# Homework-Methods

Homework on methods in Java.
Both programs run in the console and use Scanner for user input.

## Projects

| File Description 

| StudentGrader.java | calculateGrade(int score) returns a letter grade: A (90+), B (80+), C (70+), 
  D (60+), F otherwise. Includes input validation: the score must be between 0 and 100. 
| PatternGenerator.java | Asks for the number of rows and a pattern type, then prints the pattern. 
  Each pattern is a separate method: right triangle, inverted right triangle, pyramid, inverted pyramid,
  and number triangle. Includes validation for size and menu choice. 

## Example (PatternGenerator)
